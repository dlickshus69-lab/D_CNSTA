## What's new

- **The game opens the way you last set it.** Each seed has its own save folder, so the game used to start in a window again with every new seed. Now the client carries your newest display settings (window, borderless full screen, resolution) into each seed's save folder. Set it once and it sticks.
- **These notes.** The Releases page now shows what changed in each build.
