# Crash N. Sane Trilogy — Archipelago

## Play and configure

| Input | Action |
|---|---|
| F1 / Esc | Open / close the AP console |
| Tab | Complete commands, `!hint` item names and `!hint_location` location names |
| Page Up / Page Down, mouse wheel | Scroll console history |
| F7 | Toggle AP markers, labels and HUD |
| F2 (hold) | Show the popups again: items found and received, traps, ... (up to the last 300; each popup also stays 7 seconds). While holding it, scroll with the mouse wheel, Page Up/Down or the arrow keys (Home: oldest, End: newest) |
| F10 | Restore normal movement if you're stuck in Crashsanity |

Console input supports Left/Right, Home/End, Shift selection and Ctrl+A/C/V.
Automatic connection attempts stop after five failures.  
Correct the connection settings and use `/connect` to start a fresh attempt.

The level panel in the top-left corner spells it out: checks found out of the level's total and how many more are available now (in logic), whether the level clear is done, then the same for gems, the power crystal and the relic. A line is green when your items let you get more of it now, red when they reach none of the rest, and yellow once it is all done. The label over a hub entrance has three lines: the game and level, with "(All Done)" in green once every check there is found; `Checks: found/total` with how many more your items let you get now; then found/total for `Level Clear`, `C` power crystal, `G` gems, `R` relic and, with Boxsanity, `B` box checks (the level's boxes that are checks). The checks line and each of those are colored the same way.   
Each game's totals appear under its logo on the title screen and in the top-right corner of its hub: `Available checks: N (found/total found)`, green when your items reach any, and `Available levels: open/total`, how many of that game's levels you can enter now (by the hub their entrance is in).  
Approach an unlocked hub entrance to see its destination label and check counts.  
`/hubdistance_c1`, `/hubdistance_c2` and `/hubdistance_c3` show each hub's label
distance.   
Add a number to change it in game units (default 250, maximum 100000).  
Use 0 to hide that hub's labels.  
`/hubdistance 500` sets all three hubs to 500.  
Settings are saved locally and restored next time.

Useful local commands:

```text
/help
/status
/boxmarkers tint/bounds/off
/tint_opacity 0.5
/slow_tilt 0.71
/trap_test slippery
/hubdistance 500
/hubdistance_c1 1000
/hubdistance_c2 250
/hubdistance_c3 500
/outoflogic on/off
/disconnect
/connect
```

Markers normally show unchecked selected crates that are in logic. `/outoflogic on` also shows out-of-logic crates. 
`/tint_opacity` shows the current tint strength.  
Set it from 0 (no tint) to 1 (full tint), for example `/tint_opacity 0.5` for 50%. The default is 0.75.
`/slow_tilt` sets how far the Slow Trap pushes the stick (0.2 to 1, default 0.71). While Slow is on, the client tunes it itself: if Crash runs it goes down at once and never back up to that tilt, if he stands still for a moment while you push it goes up, and the result is saved. Each change is logged as `Slow tuner: ...`. The setting is saved on this computer.


Skins: skin mods for Crash (a replacement `Crash.pak`) go in `CrashNSTAP\skins`, either the mod's whole folder as it came or its `Crash.pak` renamed to `name.pak` (the README in that folder explains). Pick one with `/skin name` in the console (`/skin` lists them, `/skin default` goes back; when the seed gives Crash colors, back to Crash in those colors). When the game starts, the client's `dinput8.dll` copies the chosen skin's `Crash.pak` into the game's archives folder before the game reads it, the same as installing the mod by hand, after keeping the game's own `Crash.pak` in `skins\default`. So a new choice shows the next time the game starts: after `/skin name` the client says "Restart the game to wear it." `playstation_1` matches a skin whose name has playstation, PS1, PSX or low poly in it, `biker` one with biker in it. A skins zip (`CrashNST-Skins.zip`, on the Releases page as a release whose tag starts with "skins", which new builds never clean up) has the two skins in their folders, ready to extract next to the game's .exe. If Steam updates or verifies the game, its new `Crash.pak` becomes the default. Skin mods are other people's work, and their quirks come with them, the same as installing them by hand: the Biker Crash mod reuses Aku Aku's look files for its jacket, so Aku Aku is invisible while wearing it, and the PlayStation 1 (low-poly) Crash mod only swaps some of his textures, so his face can look shiny.

Crash colors: the YAML's color options (see Cosmetic below) color Crash's fur, chest and jaw, pants, shoes, mohawk, gloves and eyebrows. They are set once per seed and stay for the whole seed: `/colors` in the console shows them. `/colors random` picks random colors instead (V1.3.43), kept until `/colors seed` (back to the YAML's) or a new seed. Connecting to a seed puts its colors on, so going back and forth between two seeds switches the colors with them. The client makes a colored copy of the game's own Crash.pak (the one kept in `skins\default`, or the game's while it wears no skin), keeping his shading (bright colors ease off before full white, so they don't glow under strong lights): only the parts with a color change, while his eyes, soles and laces stay. It is saved as a skin named `colors_` and a code in `CrashNSTAP\skins` and chosen like one, so it shows from the next game start. The colors need the game's own Crash.pak: if the one kept in `skins\default` already has colors in it (an older seed's, kept as the game's own when `CrashNSTAP\skins` was lost), the client says so instead of making them, and verifying the game's files in Steam fixes it (the colors are made again at the next connection, so they show after one more restart). Making it takes a second or two; older combinations are deleted. The colors are for the normal Crash, so they replace a skin mod while chosen. The textures with fruit juice or ash splashed on them (`CrashFur_Fruit_C` and the like) get the colors too. A few levels and scenes carry their own copy of Crash's textures and use it instead of Crash.pak's (Lights Out, Fumbling in the Dark, some bosses and cutscenes): the client lists them in `state\color_patches.txt`, and at the next game start `dinput8.dll` adds the colored textures to the end of each of those archives and points the textures there, keeping the original records and size in `CrashNSTAP\skins\patched.txt`. When the colors change or go back to normal, it puts those archives back exactly as they were. To stop using AP after wearing colors, remove `dinput8.dll` and let Steam verify the game's files (or first connect to a seed without colors and start the game once). The console says `Crash colors: also in N levels and scenes ...` at startup. The Crash 1 island map shows its own small Crash, which stays orange. The fur and chest areas come from the "Blue Crash" skin mod (Nexus Mods, Crash Bandicoot N. Sane Trilogy mod 24), as block maps only.

The game's own sounds: NST has FMOD built in, so the client reads its sound files instead. The game keeps each sound in its own file inside the .pak archives (`sound_samples/wavs/.../name,bank,NoLoc,48000,40,0,0.igz`, an FMOD sound bank inside), so at startup, in the background, the client reads the sound files with "tnt" in their name, picks the TNT countdown and decodes it (the TNT countdown, `com_crate_tnt_countdown_01`, is FMOD MPEG audio, decoded with minimp3; FMOD's Vorbis, IMA ADPCM, FADPCM and PCM work too, Vorbis with stb_vorbis and FMOD's setup headers from vgmstream). The Nitro Trap countdown then plays it, and the client remembers it for next time (`Nitro Trap countdown: ...` in the console). If it can't play the sound, it says why and saves the sound's file to `%LOCALAPPDATA%/CrashNSTAP/state/dumps` to send. `/nitro_volume 0` to `100` sets how loud it plays (default 50, kept for next time). The client plays it the way the game would rather than bare: softened a little (the file is MP3), in stereo with a short, quiet room echo, fading in and out over a few milliseconds so it doesn't click.
DeathLink in gimmick stages (hog, polar bear, jetpack, vehicles): your deaths there are sent too. On a ride a death is also seen when the ride's health runs out (the jet ski levels never set the game's usual death switch). A DeathLink you receive on a ride (gimmick stages) waits and gets you in the next level you play on foot (once, however many came in), because the game's death on foot breaks the ride (on Coco's jet ski it left her invisible and respawned her in the wrong place) and taking a life instead didn't work. The Crash 2 jet-board levels (Hang Eight, Air Crash, Plant Food) count as on foot since V1.3.43: a DeathLink there strikes on foot and waits only while Crash is on the board. In the Testing build the log lists what each ride's scripts get (`Ride research: ...`), to find the game's own end of a ride for DeathLink. The log shows what the client found on each ridden form (`Death watch: ...` or `DeathLink: ... has no PlayerDied`), so send a log if a death there isn't sent.

DeathLink and the game over screen (V1.3.43): DeathLinks that come while the game over screen is up are dropped (Crash is already out), and a DeathLink only strikes once the level is open, with Crash able to move for 1.5 seconds and the level's HUD on screen (they used to strike as the level opened after a game over, leaving the screen white).

Death counter: the top-right corner always shows the seed's death count ("Deaths: N"), in the hubs and in levels, DeathLink or not. With DeathLink on and other players in the room it's everyone's deaths together, with each player's count under it (0 until they die). It counts your deaths that were sent and every DeathLink. Since V1.3.45 (Stable V1.3.3) the count is shared through the room: every client writes each death it sees to the room's data on the server (by the DeathLink's time and player, so the same death from several clients is one), and reads everyone's back, so all clients show the same numbers, also for deaths while a client was offline (as long as one client was online to see them). The first time a client connects with it, its count so far goes along, and the shared count carries on from the highest one. Without DeathLink it counts only your own deaths.

DeathLink, bonus rounds and time trials: dying in a bonus round only ends the bonus round, and dying in a time trial only ends the run, so neither is sent to anyone; neither is Restart from the pause menu. A DeathLink you receive during a time trial still gets you. A DeathLink received during a bonus round fails the bonus round (no life lost), and you can try it again.
`box_item_spoilers` in the yaml can color markers by item category. Chat and `!` commands go to the AP server.

When item spoilers are enabled, the client scouts selected locations on connection without creating hints. Item flags are cached per seed and slot for offline play. Boxes use the normal marker color until their flags arrive.

## World options

On the options page and in generated YAMLs the options are grouped: Game Options, Goal, Levels, Crystals / Gems / Relics, Sanity Options, Traps, Bosses, Cosmetic, then Item & Location Options.

Secret destinations include required source levels automatically.

- Choose any campaign combination, level pool and level counts.
- `starting_levels`: starting entrances per enabled campaign, from 1–31 (default 2), capped at the selected regular entrances. Fill the earliest available hub areas first. Very tight settings (hub and level locks, few check types, no boxsanity) can leave a seed that opens with only one to three checks, or whose progression items fill most of its locations; AP can't place items in those, so the generator adds starting levels (at most eight, earliest hub area first, only ones that help) until the seed opens with at least 4 checks and progression fills at most 65% of its locations. Generation logs `... also starts with ...` when it does. Later areas start unlocked only if the requested count needs them or the pool has no earlier entrances. The selected pool is preserved.
- `secret_exit_checks` (Levels section, default off): taking a secret exit is a check. Crash 2: Air Crash, Bear Down, Un-Bearable, Hangin' Out and Diggin' It; Crash 3: Road Crash and Dino Might! (only in the levels you selected; Crash 1 has none). The exit counts even when the level it leads to is still locked. Logic: the level's own access, plus the Yellow Gem for Dino Might! and, with Ability Shuffle, Body Slam for Diggin' It. The console says `Secret exit found: ...`, and the level's top-left panel and its hub label get a `Secret Exit:` line (red: you can't reach it yet, green: you can now). Needs a new seed.
- `level_shuffle`: `off`, `within_campaign` or `across_campaigns`. If you ever slip into a level that is still locked (for example by pressing confirm the moment a hub loads), the game sends you straight back to the hub. Starting Crash 1 puts Crash on the map at the earliest open level, not wherever the save last left him.
- `boxsanity`: 0–100% of the boxes turn into ap locations. There are 5291 boxes across 85 stages.
- `white_gem_checks`, `colored_gem_checks`, `crystal_checks`, `relic_checks`: percentages of collectible locations to select as AP checks. Unselected collectibles stay vanilla or are overwritten by collectible_rewards.
- `collectible_rewards`: per-category `randomized`, `vanilla` or `precollected`. Randomized: Default shuffle behaviour. Vanilla: selected checks keep their normal items. Precollected: randomizes selected checks and gives the unselected collectibles from the start.
- `goal`: `all_cortex`, `cortex_1`, `cortex_2`, `cortex_3`, `level_clears` or `token_hunt`. `goal_count` applies only to level clears and is capped at the selected regular-level count.
- `require_all_bosses`: off by default. For Cortex goals, require every boss, including Cortex, in the goal campaigns. Required bosses are added even if excluded from the level pool. This does not affect level-clear or token-hunt goals.
- `token_percentage`: replace 1–100% of the remaining filler slots with AP Tokens (default 20%). `token_required_percentage`: collect 1–100% of those tokens to win (default 80%). Both round up. Progression, collectible rewards and useful items keep their slots. Token hunt needs at least one filler slot.
- `death_link` is optional and defaults off. 
- Bosses (Stable V1.3.1, for now only Papu Papu; every other boss stays as the game has him): `harder_bosses` (default off) turns on his red rule: he glows red at the start of the fight and after each hit, until the slam that follows his next spin, and landing on him while he's red doesn't count as a hit (Crash bounces off and gets hurt: an Aku Aku mask takes it, or Crash dies). With it on, `boss_health` (100–200%, default 150) gives him one more hit every 25% (5 hits at 100, 6 at 125, 7 at 150, 8 at 175, 9 at 200; the bar gets a notch for each), and `boss_speed` (100–200%, default 150) makes him spin faster and wait less before his spins. `harder_bosses_aku_aku` (default off): with it off, Crash has no Aku Aku mask in a harder boss fight (masks from crates and items there come in the next level); on, masks work there as usual. Without `harder_bosses`, health and speed do nothing.
- Cosmetic: `crash_fur_color`, `crash_chest_color`, `crash_pants_color`, `crash_shoes_color`, `crash_hair_color` (the mohawk), `crash_gloves_color` and `crash_eyebrows_color` each take `default` or a color (red, dark_red, orange, yellow, gold, lime, green, dark_green, teal, cyan, light_blue, blue, navy, purple, violet, pink, magenta, brown, tan, white, light_gray, gray, black, and bright_white, which can glow under strong lights), or `random`, and the client wears them from the next game start, for the whole seed (see Crash colors above).
- `crashsanity` is experimental and defaults off.
- `relic_requirement`: `any` (default), `gold_or_platinum` or `platinum`. The minimum relic tier that sends a relic check. A lower tier is not awarded, so you can replay the time trial. Relic checks stay in logic; above `any`, Crash 2 relics expect Crash 2 Speed Shoes (not on the polar bear, jetpack or jet board) and Crash 3 on-foot relics expect Crash 3 Speed Shoes (gold) or every Crash 3 power (platinum).
- Filler / Traps: `wumpa_fruit_weight` and `one_up_weight` (0–100, default 50 each) set the mix of filler items (the slots left after progression, tokens and traps); both at 0 is an even mix.
- `aku_aku_mask_weight` (0–100, default 0): how often a filler item is an Aku Aku Mask. Crash gets a mask in the next level once he can move, also with Aku Aku Sanity before you've found the Aku Aku item. It takes one hit like a crate's mask; on top of a mask it gives the next one, the way a crate's does: two masks make Aku gold, three give the invincibility. In a boss fight one is enough: a mask comes there only while Crash has none, one per fight, and the rest wait for the next level. After a seed's goal is done (every item arrives at once), `/skip_filler yes` counts every 1-Up, Wumpa Fruit and Aku Aku Mask received so far as given, so none of them comes; ones received later come as usual.
- `trap_fill_percentage`: 0–100% (default 0) of junk items (Wumpa/1-Up) become traps. `life_loss_trap_weight`, `move_lock_trap_weight`, `reverse_controls_trap_weight`, `freeze_trap_weight`, `slippery_trap_weight`, `slow_trap_weight`, `darkness_trap_weight` and `nitro_trap_weight` (0–100) decide the mix. **Life Loss Trap** (experimental): you lose one life through the game's own extra-life reward. **Move Lock Trap**: no spin, slide, body slam or crouch. With Ability Shuffle it waits until you have at least one of those moves to lock ("Move Lock Trap incoming! It strikes once you have a move to lock."). **Reverse Controls Trap**: left/right and forward/back swap on the stick, d-pad, arrows and WASD. **Freeze Trap**: all input stops for 6 seconds. **Slippery Trap**: every floor Crash stands on turns into the game's own ice (the same ice as Snow Go) for the trap's time, starting at once, and goes back to normal at once when it ends. The client finds the game's ice a few seconds after the first level loads; until then, or for a character without the game's ice, it falls back to a stick-momentum version (Crash speeds up slowly, slides on after you let go). No effect in gimmick levels (the HUD shows "Slippery (off here)"). **Slow Trap**: Crash can only walk (stick and d-pad become a steady walking tilt, tuned with `/slow_tilt`; controller only), with no effect in gimmick levels or the chase levels Boulders, Boulder Dash, Crash Dash, Bone Yard and Dino Might! (the HUD shows "Slow (off here)"). **Darkness Trap**: the darkness creeps in over 5 seconds, the light closing in on Crash, until the screen is dark except a soft spotlight that follows him, like Lights Out; it lifts over 1.5 seconds when the trap ends; no effect in gimmick levels, except underwater (Under Pressure, Deep Trouble) and on the Crash 2 jet board (the HUD shows "Darkness (off here)"). **Nitro Trap**: "NITRO INCOMING! 3, 2, 1" appears at the top of the screen in step with a TNT crate's countdown (a number every 1.37 s, the TNT's own beat, measured from a clip of one), then a coin flip decides what happens: half the time the game spawns a real Nitro crate about 1.3 crates ahead of Crash in the direction he is running (in the middle of a jump, at his height, floating in midair), close enough to surprise you but far enough to jump it or stop; the other half a Nitro appears high above Crash and drops onto the spot where he is standing in 0.31 seconds, and blows up where it lands even if it missed him, so keep moving and get clear of the spot (the client sends it the Nitro's own explode steps; the log says `set it off where it landed` and then `it went off where it landed`). What the trap needs from the level (the Nitro, a spawner to borrow, where the crates are) is gathered on a thread of its own every few seconds, only while a Nitro Trap waits or runs, so the game doesn't hitch. If it comes up "ahead" while Crash isn't running, he gets 1.5 seconds to start, then it falls instead. Each number ticks: with the game's own TNT countdown sound once the client has found it in the game's sound files (see "The game's own sounds" below), otherwise with the client's own tick. The falling Nitro is moved with the game's own set-position and its physics body with the game's own body calls (the body works in meters, the game in inches, so the client converts), so what you see and what touches Crash fall together (the log says `Nitro drop: landed (the game has it at ..., its body at ...)`, and the two should match). Trap Nitros don't hop, so they stay where the trap put them instead of flying back to the level Nitro they were borrowed from. While Crash is jumping or falling, the ahead Nitro appears straight ahead at his height (the way he last ran, also for a jump on the spot) and floats there (if the game lets it drop, the client holds it up; the log says `held up`). On the ground it uses floor he already stood on when it can (an earlier try at that spot), otherwise straight ahead along the line he is running. A spot straight ahead must be on the way to a crate further ahead, or next to floor he stood on: crates are always somewhere he can get to, so the Nitro doesn't end up inside a wall where his way bends. It waits while he is turning or standing still, or when nothing ahead is safe. It works in every level: the game keeps its Nitro loaded everywhere, and a spawner that counts nothing toward the boxes makes it, so the trap's Nitro never counts as a box. It also strikes in some gimmick levels: the hog (Hog Wild, Whole Hog), the Crash 2 jet board (Hang Eight, Air Crash, Plant Food) and polar bear (Bear It, Bear Down, Un-Bearable, Totally Bear), as well as the chase levels. In the scuba levels (Under Pressure, Deep Trouble) it only ever appears ahead of Crash, floating in the water, never dropping onto him, and waits as long as it takes for a spot ahead. It never happens in the jetpack, motorcycle, plane, Coco's jet ski, Coco's tiger or Baby T levels; until it can strike, it waits ("Nitro Trap incoming!") without holding up other traps. It's never lost: if Crash dies during the countdown (or you open the pause menu), the countdown and its sound stand still and go on together once he can move again, and if the level changes before the Nitro comes, the trap starts over in the next level where it works. `trap_duration` (10–120 s, default 30) sets the timed traps; another trap of the same kind that arrives while one runs (or waits its turn) adds no time, so a trap never lasts longer than `trap_duration` ("... again! It's already on, so it keeps its time."). Slow, Slippery and Reverse Controls take turns, because together they ruin each other: if one arrives while another of them is running, it waits (the HUD shows it as "(next)" with its time standing still, and the client says "..., once the Slippery Trap ends!"), then gets its full time when the running one ends; they go in the order they arrived. **Mercy:** every time Crash dies, each timed trap (running, or waiting its turn) loses 5 seconds, and one with less than 5 seconds left ends. Traps wait until you are in a level and Crash has been able to move for 1.5 seconds (not during the level's intro or right after a respawn), fire one at a time at least 10 seconds apart, show a timer on the HUD, and never repeat after reconnecting. Running traps pause in hubs, maps, the pause menu, other menus and loading screens, and while Crash dies and respawns (the HUD shows "Paused:"), and continue when you can move again. A trap with no effect in the level you're in (Move Lock and Slippery in gimmick levels, Slow also in chase levels, Darkness in its exempt stages) shows "(off here)" with its time standing still, and runs in the next level where it works; they never affect menu controls. F10 does not cancel them. For traps, the Crash 2 jet-board levels (Hang Eight, Air Crash, Plant Food) count as gimmick levels too. Gimmick stages ignore Move Lock.
- `ability_shuffle`: `off` (default), `start_with_spin` or `shuffle_spin`. Find **Spin**, **Body Slam**, **Crouch Jump** (crouch and high jump) and **Slide** as items; each works in all three games and alongside Crashsanity. Logic is a cautious draft: clears need Spin (with Spin shuffled, only your easiest starting level is expected by jumping), gems/relics/boxes need Spin in Crash 1 and every move in Crash 2 and 3. Gimmick stages (hog, polar bear, jetpack and Crash 3 vehicles) keep vanilla controls, as with Crashsanity. Logic follows the level you actually play, so it works with level shuffle across campaigns. Each campaign gets at least two starting levels. Every move and every ability of your campaigns (including both Speed Shoes) is always in the seed to be found; if the seed is full you start with a few relic, crystal or white gem rewards to make room, which a little `boxsanity` avoids. A newly found Crouch Jump applies after re-entering the level. Until you have Crouch Jump or Slide, the crouch/slide button does nothing. Press **F10** if a move you need is missing. The console prints each attack name once (`Ability Shuffle: attack ...`); please report what Spin shows as.
- `spin_placement` (with `shuffle_spin`): `early_to_mid` (default) keeps Spin out of your starting levels and puts it on a random check you can reach without Spin, behind unlocks you find along the way (two or more when the seed allows). `anywhere` lets the generator put it on any check logic reaches without it. Seeds stay beatable either way. (`early` was removed; older YAMLs that say `early` get `early_to_mid`.)
- `aku_aku_sanity` (experimental, default off): Aku Aku is an item. Lights Out and Fumbling in the Dark (Crash 1) are pitch dark without his light, so logic expects the Aku Aku item for everything in them (you can still go in). Until you find it, Aku Aku crates give no mask in any of the three games, like a move you haven't unlocked; once you have it they work normally. The client uses the game's own "no Aku Aku masks" switch; the log says `Aku Aku lock: ...` when it turns it on or off.
- `ability_logic` (with Ability Shuffle): `cautious` (default) expects Spin for level clears (except your easiest starting level) and every move for gems, relics and boxes in Crash 2 and 3, so before Spin you can only play gimmick stages. `relaxed` expects only jumping for level clears, power crystals and boxes (enemies can be jumped on, crates jumped on or hit from below), so Spin and the other moves can be on almost any of those. With `spin_placement: anywhere` a move can be in your first few checks in one seed and leave you jumping around for hundreds of checks in the next. In a multiworld, `progression_balancing` pulls your important items (moves included) earlier; set it to 0 to let them land anywhere. Bosses still need Spin; gems and relics keep the cautious needs. In both modes, levels that can't be cleared by jumping alone need their move for everything past the obstacle (The Great Gate and Native Fortress: Spin; Crash Crush and Bee-Having: Slide; Sewer or Later: Spin and Crouch Jump; The Eel Deal's bonus round: Spin; arrow crates, crates sitting on a TNT or Nitro and crates in stacks four high: Spin; iron-bound crates and Turtle Woods' underground room: Body Slam; gimmick stages keep vanilla controls and need no moves), so logic never sends you there without it and you never need Crashsanity's vanilla controls to get through. The four basic moves (Spin, Body Slam, Crouch Jump, Slide) are all Ability Shuffle items. Tell me any other level that needs a move, and it gets added.

Totally Bear/Fly, Hot Coco and Eggipus Rex require their usual secret paths and the chosen access locks.  
CB3 relic-room entrances follow AP access locks instead of vanilla relic requirements.

With Hub Area Locks enabled, each **Crash 1 - Progressive Island Access** opens the next island (two copies total).  
Each **Crash 2 - Progressive Elevator Access** opens the next warp-room floor (four copies total).  
Starting entrances fill the earliest selected hub areas first. Any required later-area copies are granted from the start.
Crash 3 uses a separate **Hub Section Unlock** for each gated section.  
Boss defeats do not open hub areas.

Leaving a level returns to the physical entrance used, including shuffled levels in another campaign.
Starting a campaign without entrance history uses its default hub spawn.

Filler rewards are Wumpa Fruit and 1-Ups. Rewards received on hubs wait until gameplay and apply once.

## Update, disable and troubleshoot

Replace the package's `dinput8.dll` and merge its `CrashNSTAP` folder into the game folder.

To disable AP, close NST and remove `dinput8.dll` from the game folder.

Local profiles, connection settings, display settings and runtime logs are under `%LOCALAPPDATA%/CrashNSTAP/state` (each game writes `logs/client-<date>_<time>.log`, named after when the game started, the same text as the Debug window, handy to attach; only the newest 10 are kept, and you can delete them any time). Selecting text in the Debug window no longer pauses the game: the window catches up when the selection ends.
The game-folder loader log is `CrashNSTAP/loader.log`
